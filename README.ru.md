# dsh-telegram-app

Мост DeepSeek Harness ⇄ Telegram: слой 1 — чат (работает сразу, без публичного адреса), слой 2 — панель Mini App (написана, но выключена до выбора транспорта).

**Без домена, туннеля и открытых портов.** В базовом режиме бот сам опрашивает Bot API исходящими запросами, поэтому слой 1 работает на машине за NAT. Публичный HTTPS-адрес нужен только для необязательной панели Mini App (слой 2), и она по умолчанию выключена.

Английская версия: [README.md](README.md).

## Возможности

- Привязка чата по контрольному токену (SHA-256, на диск попадает только дайджест).
- Навигация «меню → воркспейсы → чаты → работа с чатом» (L0–L3), одно редактируемое сообщение на экран.
- Отправка промптов обычным текстом в привязанную сессию; ответ агента не пересылается автоматически, доступен по `/last` и кнопке.
- Управление сессиями: `/new`, `/use`, `/unbind`, `/stop`.
- История: `/last [n]` (по умолчанию 5, максимум 10).
- Уведомления о завершении хода (`running → idle`) с троттлингом ошибок.
- Русский и английский текст в чате, переключается одной настройкой. Имена команд не переводятся, поэтому привычка и скрипты продолжают работать.
- Запросы разрешения с кнопками ✅/⛔; режимы `ask`/`notify`/`off`.
- Слой 2: панель Mini App (выключена по умолчанию, включается публичным HTTPS-адресом).
- Все офлайн-тесты (213), без живого Harness и Telegram.

## Требования

- Node.js `>=22.19` (см. `engines` в `package.json`).
- Установленный DeepSeek Harness (DSH).
- Бот, созданный в @BotFather.
- Приватный чат с ботом (группы игнорируются).

## Установка

```bash
# Установка ссылкой (правки кода подхватываются без переустановки)
dsh plugin --profile web add link:/путь/к/репозиторию/dsh-telegram-app

# Проверка (только для слоя 2, когда включён публичный адрес)
curl -s http://127.0.0.1:3080/tg-app/api/health

# Удаление
dsh plugin --profile web remove dsh-telegram-app
```

После установки в DSH в разделе **Plugins** появится карточка `telegram-app` с кнопкой **Configure**.

## Настройка

### Поля конфигурации (из `lib/schema.mjs` и `index.js`)

| Поле | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `botToken` | string | `''` | Токен от @BotFather. `.role('secret')` — форма рендерит только на запись. |
| `controlToken` | string | `''` | Секрет для привязки чата. Генерируется автоматически при первом запуске. `.role('secret')`. |
| `locale` | string | `'ru'` | Язык бота в чате: `ru` или `en`. См. раздел «Язык». |
| `publicBaseUrl` | string | `''` | Публичный HTTPS-адрес для слоя 2. Пусто = слой 2 выключен. |
| `appPath` | string | `'/tg-app'` | Путь панели Mini App. Только при включённом слое 2. |
| `apiBase` | string | `'https://api.telegram.org'` | Базовый URL Bot API. |
| `proxy` | string | `''` | HTTP-прокси для Bot API. |
| `allowedUserIds` | number[] | `[]` | Доп. Telegram user_id, которым разрешён доступ. |
| `cwd` | string | `''` | Рабочий каталог для `/new`, если не определился автоматически. |
| `sessionLimitDefault` | number | `5` | Сколько чатов показывать в папке (L2). |
| `workspaceSortDefault` | string | `'registry'` | Порядок папок: `registry` или `activity`. |
| `notifyDefault` | boolean | `true` | Уведомления по умолчанию для новых чатов. |
| `notifyOnIdle` | boolean | `true` | Отправлять уведомление при завершении хода. |
| `notifyMinRunSeconds` | number | `20` | Игнорировать повороты короче N секунд. |
| `approvalMode` | string | `'ask'` | `ask` / `notify` / `off`. |
| `approvalTimeoutSec` | number | `180` | Таймаут вопроса разрешения. |
| `sessionTokenTtlSec` | number | `43200` | TTL токена сессии слоя 2 (12ч). |
| `initDataMaxAgeSec` | number | `86400` | Максимальный возраст `initData` слоя 2 (24ч). |
| `pollTimeoutSec` | number | `30` | Long-polling таймаут Telegram. |
| `statePath` | string | `''` | Путь к `state.json`. Пусто = `<DSH_HOME>/telegram-app/state.json`. |

**Важно про форму настроек:**
- Форма в **Plugins → Configure** появляется только если в схеме есть хотя бы одно поле `.volatile()`. В плагине помечены все поля, которые перечитываются на лету.
- Поля `.role('secret')` (`botToken`, `controlToken`) рендерятся write-only: в UI они выглядят пустыми даже при заданных значениях — это защита. Чтобы сменить, сотри и введи новое.
- Переменные окружения (`const ENV` в `index.js`): `DSH_TG_BOT_TOKEN`, `DSH_TG_CONTROL_TOKEN`, `DSH_TG_PUBLIC_URL`, `DSH_TG_APP_PATH`, `DSH_TG_API_BASE`, `DSH_TG_PROXY`, `DSH_TG_CWD`, `DSH_TG_STATE_PATH`, `DSH_TG_LOCALE`, `DSH_TG_SETTINGS_NS`, `DSH_TG_ALLOWED_USERS`.
- **Переменная окружения перекрывает конфиг.** Это обратное обычному правило, и так сделано намеренно: Harness прогоняет конфиг плагина через схему до его запуска, поэтому поле с умолчанием всегда приходит уже заполненным. Если бы побеждал конфиг, все переменные для полей с непустым умолчанием (`locale`, `appPath`, `apiBase`) молча ничего бы не делали — настройка выглядела бы применённой, а бот говорил бы по-старому.
- Патч профиля `cordis.patch.yml` **заменяет** секцию `config` целиком, а не сливает. Указывай все нужные поля.

### Язык

Бот говорит по-русски (`ru`) или по-английски (`en`). Язык задаётся полем `locale` — в форме настроек, в `cordis.patch.yml` или переменной `DSH_TG_LOCALE`; по умолчанию `ru`. Значение нормализуется: `EN`, `en-GB` и `en_GB` — всё английский, а всё непонятное откатывается к русскому, а не оставляет бота молчащим.

Настройка действует на **всё развёртывание**, а не на отдельный чат: один бот — один язык. Применяется при следующем запуске; тогда же бот заново публикует подсказки команд в Telegram.

Что переводится, а что нет:

| | |
|---|---|
| Переводится | Экраны, кнопки, **описания** команд, уведомления, карточки разрешений, сообщения об ошибках, единицы времени (`5 мин` → `5 min`). |
| Не переводится | **Имена** команд — `/menu` остаётся `/menu`. Данные: названия сессий, имена папок, пути к файлам и ответы самого агента. |

Числительные согласуются по правилам своего языка, а не по общему правилу: русскому нужны три формы (`1 сессия`, `2 сессии`, `5 сессий`), английскому — две (`1 session`, `2 sessions`), поэтому согласование живёт рядом со словами, а не в одном общем помощнике.

Отсутствующий перевод откатывается сначала к русскому, затем к самому ключу — пробел в словаре виден как одна строка не на том языке, а не как пустое сообщение.

> **Слой 2 пока только на русском.** У необязательной панели Mini App (`web/`) свой интерфейс, и он существует только на русском. Слой 1 — весь чат целиком — двуязычен полностью.

### Привязка чата

1. При первом запуске плагин генерирует `controlToken` и сохраняет SHA-256 дайджест в `state.json`.
2. Значение токена показывается в форме настроек (поле **Control token**).
3. Скопируй его и отправь боту **одним сообщением** в чат.
4. Бот ответит «✅ Чат привязан.» и пришлёт клавиатуру с кнопкой «🏠 Меню».
5. На диск попадает только дайджест. Если токен сменён в настройках, старые чаты не отвязываются.

## Команды

| Команда | Действие |
|---|---|
| `/start`, `/menu` | Открыть L0 (меню) |
| `/chats`, `/chats <n>` | L1 (воркспейсы); с номером — сразу L2 |
| `/use <n\|id>` | Привязать сессию и показать L3 |
| `/new [путь]` | Создать сессию (порядок: аргумент → папка привязки → `cwd` → первая папка) |
| `/last [n]` | Последние n сообщений (по умолчанию 5, максимум 10) |
| `/stop` | Отменить текущий ход |
| `/status` | Чат, привязка, сессия, счётчики, версии |
| `/settings` | Открыть экран S |
| `/notify on\|off` | Включить/выключить уведомления для этого чата |
| `/limit <3\|5\|10\|15>` | Сколько чатов показывать в папке |
| `/sort registry\|activity` | Порядок папок |
| `/unbind` | Отвязать сессию (саму сессию не трогает) |
| `/unpair` | Снять авторизацию чата (с подтверждением) |
| `/whoami` | `user id`, `chat id`, статус (работает без авторизации, throttled) |
| `/help` | Справка |

Пустой текст — игнор. Длиннее 8000 символов — отказ (файлы слой 1 не принимает).

## Экраны и кнопки

### L0 — Меню
- Текст: «🏠 DSH», статус привязки, счётчики.
- Кнопки: [📁 Воркспейсы], [⚙️ Настройки].

### L1 — Воркспейсы
- Только папки, где есть подходящие сессии.
- Кнопки на каждую папку, [🔄 Обновить], [⚙️ Настройки], [🏠 Меню].

### L2 — Чаты папки
- Последние N чатов (настройка `/limit`).
- Номер, статус (🟢/⚪), 📌 если привязан, 📱 если создан ботом.
- Кнопки: [⬅️ Воркспейсы], [⚙️ Настройки], [🏠 Меню], [➕ Новая в этой папке].

### L3 — Карточка сессии
- Заголовок, id, состояние, «последний ответ: ...».
- Кнопки: [⏹ Стоп], [📄 Последние 5], [🔄 Обновить], [⬅️ К чатам], [⚙️ Настройки], [🏠 Меню].

### S — Настройки
- Значения применяются тапом, переживают перезапуск.
- Ряды: лимит чатов, сортировка, уведомления.
- Кнопка [⬅️ Меню].

## Уведомления

Приходят при переходе сессии `running → idle`. Содержат: заголовок сессии, длительность (`runDuration`). Троттлинг: не чаще раза в 5 минут на сессию; только в чаты с включённым `notify`; игнорируются повороты короче `notifyMinRunSeconds`.

## Запросы разрешения

Когда агенту нужно подтверждение (опасное действие), бот присылает сообщение с двумя кнопками: ✅ Разрешить, ⛔ Отклонить. Режимы:
- `ask` — ждёт ответа в чате.
- `notify` — только дублирует вопрос, не блокирует.
- `off` — молчит.

Если браузер подключён (слой 2), подтверждения могут уходить и туда.

## Слой 2: панель Mini App

- Что это: веб-панель в Telegram (кнопка «Открыть в Web App»).
- Что нужно: публичный HTTPS-адрес (`publicBaseUrl`), валидный сертификат. Без него маршрут `/tg-app` не регистрируется.
- Что происходит без него: слой 2 выключен, всё работает через слой 1 (чат).
- Токены сессии: живут в памяти, TTL `sessionTokenTtlSec` (12ч). Проверка `initData` через HMAC_SHA256, максимальный возраст `initDataMaxAgeSec` (24ч).

## Архитектура

```
index.js          — вход: монтирование, config, poll loop, approvals, уведомления
lib/chat.mjs      — маршрутизация команд, навигация, callback-обработчики
lib/screens.mjs   — тексты экранов (чистые функции, покрыты тестами)
lib/nav.mjs       — фильтры, группировка по папкам
lib/state.mjs     — state.json (schema v1), атомарная запись
lib/markup.mjs    — схема callback_data, сборка клавиатур
lib/format.mjs    — время, усечение, лимиты Telegram
lib/bot.mjs       — клиент Bot API (long polling)
lib/sessions.mjs  — обёртка над Session API
lib/schema.mjs    — Config-схема для формы настроек
lib/routes.mjs    — HTTP-поверхность слоя 2
lib/auth.mjs      — проверка initData слоя 2
web/              — страница панели слоя 2
locale/           — название и описание для карточки
```

**Клиентская половина** (`lib/client.js`): заполняет слот `plugins.row.config` для формы в UI. Написана на диалекте `window.__ModuleLoader__.load`, не как ES-модуль. Без неё форма настроек не появляется. Все секретные поля помечены `.role('secret')` и `.volatile()`.

## Безопасность

- Только приватные чаты. Из группы — одно сообщение-подсказка, дальше игнор.
- Контрольный токен: сравнение за постоянное время по SHA-256 дайджестам. На диск — только дайджест.
- 5 неверных попыток → пауза 15 минут.
- Ответы неавторизованным — не чаще раза в 30 секунд.
- Секреты не логируются.
- Файл состояния `0600`, атомарная запись (временный файл + `rename`).
- Слой 2: подпись `initData`, TTL токенов, ничего в `localStorage`.

## Решение проблем

| Симптом | Причина | Что делать |
|---|---|---|
| Поля токенов пустые в форме | `.role('secret')` — write-only | Сотри и введи новое значение; старое хранится, но не показывается |
| «Кнопка устарела» | `callback_data` не распознан (устаревший префикс) | Нажми «🏠 Меню» и перейди заново |
| «История недоступна» | Session API недоступен или сессия удалена | Проверь Harness; если сессия удалена — привяжи другую |
| «В этой сессии пока нет сообщений» | История пуста | Отправь промпт, подожди ответа |
| Плагин Running, но настроек нет | Нет ни одного `.volatile()` поля в схеме | Проверь `lib/schema.mjs`; должно быть минимум одно |
| Сообщение не уходит боту | Бот не авторизован или неверный `botToken` | Проверь токен в настройках; убедись, что бот запущен |
| «Сессия недоступна. Привязка снята» | Сессия архивирована/удалена | Выбери другую сессию через `/use` или `/chats` |
| «Слишком много неверных попыток» | 5 ошибок `controlToken` | Подожди 15 минут или смени токен в настройках |
