Вход в Harness

Telegram подтвердил, что панель открыта из этого бота. Введи контрольный токен, который задан на стороне Harness, — и этот чат будет привязан.

Что именно проверяется

Панель присылает подписанный Telegram initData. Сервер проверяет подпись ключом бота (HMAC_SHA256(bot_token, "WebAppData")) и свежесть auth_date, затем сверяет контрольный токен. Только после этого chat id сохраняется на диск — посторонний не увидит ни одного сообщения агента.
